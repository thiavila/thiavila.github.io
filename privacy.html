Política de privacidade do email-triagem

Atualizada em 31/10/2026.

O email-triagem é um script de uso pessoal, que roda apenas no computador do autor, Thiago Avila, e acessa somente a conta Gmail dele (thiagodeavilag@gmail.com). Não há outros usuários.

Dados acessados

Com a autorização do Google, o script lê os e-mails da caixa de entrada e, quando o autor aprova, aplica marcadores, arquiva ou move mensagens para a lixeira.

Armazenamento

As mensagens e os resultados ficam guardados localmente, no computador do autor. O token de acesso fica no Keychain do macOS. Nada é publicado nem vendido.

Compartilhamento

Para classificar cada e-mail, o remetente, o assunto e um trecho do corpo são enviados à API do TypeSafe (Jev). Nenhum outro terceiro recebe dados.

Uso de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, inclusive os requisitos de Uso Limitado.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
